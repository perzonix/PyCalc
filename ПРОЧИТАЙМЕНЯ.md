# 🧮 PyCalc

Современный и минималистичный калькулятор с графическим интерфейсом, написанный на Python с использованием библиотеки `customtkinter`. Благодаря чистому дизайну, интерфейс приложения выглядит очень аккуратно и отлично впишется в минималистичное рабочее пространство.

🔗 **Репозиторий проекта:** [perzonix/PyCalc](https://github.com/perzonix/PyCalc)

## ✨ Особенности
* **Современный дизайн:** Поддержка светлой и темной темы с возможностью переключения по кнопке "💡".
* **Продвинутая логика:** Поддержка не только базовых операций, но и возведения в квадрат (`x²`), степеней (`^`), извлечения квадратного корня (`√`), работы с дробями (`1/x`), изменения знака (`+/-`) и вычисления процентов (`%`).
* **Поддержка клавиатуры:** Полная интеграция с клавиатурой для ввода цифр, операторов, очистки (Escape), удаления символов (Backspace) и вычисления (Enter).
* **История вычислений:** Отображение предыдущего действия над основным экраном ввода.
* **Кастомная иконка:** Автоматическая загрузка логотипа проекта при наличии файла `logo.ico` в директории.

## 📂 Структура проекта
* `main.py` — главный файл для запуска приложения.
* `src/` — исходный код логики (`logic.py`) и настроек интерфейса (`config.py`).
* `assets/` — ресурсы проекта (иконка `logo.ico` и скриншоты).
* `requirements.txt` — список зависимостей.

## 🚀 Установка и запуск

1. Убедитесь, что у вас установлен Python.
2. Клонируйте репозиторий:
   ```bash
   git clone [https://github.com/perzonix/PyCalc.git](https://github.com/perzonix/PyCalc.git)
   cd PyCalc
   ```
3.Установите необходимые зависимости:
  ```bash
  pip install -r requirements.txt
  ```
4. Запустите главное приложение:
  ```bash
  python main.py
  ```

## ⌨️ Горячие клавиши

Приложение полностью поддерживает ввод с клавиатуры:

* `0`-`9` — Ввод цифр
* `+`, `-`, `*` (или `x`), `/` — Базовые математические операции
* `^`, `%` — Возведение в степень и вычисление процента
* `Enter` или `=` — Вычислить результат
* `Backspace` — Удалить последний введенный символ (`⌫`)
* `Escape` — Полностью очистить поле ввода и историю (`C`)
